Media Text

Two-column image + text layout with simple, focused API.

<media-text image="photo.jpg" title="Title">

Legacy Concierge provides personalized healthcare services tailored to your unique needs. Our team of dedicated professionals ensures you receive the highest standard of care in the comfort of your home.

Learn More
<media-text image-position="left|right">

image-position="left" (default)

The image appears on the left side by default, with text content on the right.

image-position="right"

Set image-position="right" to flip the layout with text on the left.
<media-text ratio="50-50|60-40|40-60">

ratio="60-40" (larger image)

60-40 ratio gives more visual emphasis to the image while keeping text compact.

ratio="40-60" (larger text area)

40-60 ratio provides more space for longer text content while still featuring a supporting image.

Perfect for detailed descriptions or multiple paragraphs.
<media-text align="start|center|end" reverse-mobile image-fit="cover|contain">

align="center" (vertical centering)

Short text that vertically centers with the image.

reverse-mobile (image below text on mobile)

On mobile devices, the text will appear first with the image below. Try resizing your browser to see the effect.
